Complete module index
=====================

Everything below this page is generated by ``sphinx-apidoc`` from
``core/gain`` on every documentation build: one page per module, in
alphabetical order, for every public module in the package — whether or not
it is part of the API the curated chapters describe. Use it as a reference
when you already know the name you are looking for. If you do not, the
chapters before this one are the intended way in: they cover the objects an
extender actually calls, in the order they depend on each other.

Two things to know when reading it. First, it is regenerated rather than
committed, so it always reflects the source tree it was built from and
carries no per-page "last updated" stamp. Second, it is emitted without index
entries: cross-references throughout the documentation resolve to the curated
pages, not to this tree, so a class documented in both places has exactly one
link target.
